# Pre-registered: does the ZW3-ASL relationship hold under a meridional
# wind definition of ZW3?

Written before the v-wind data was examined.

## Framing, stated in advance

This is a SENSITIVITY test, not an independent replication. Geostrophy
predicts phi_v = phi_Z + 30 deg exactly, in which case the phase
anomalies are identical and the regression is uninformative. The test
has value only insofar as the two phase series diverge.

## Analytic prediction (independent of any fitted relationship)

P1. The circular-mean offset phi_v - phi_Z should be near +30 deg on the
    120 deg cycle. An offset near 30 or 90 indicates quadrature, which is
    the physical claim; the sign distinguishes convention details. An
    offset near 0 or 60 would refute quasi-geostrophic consistency and
    indicate an error in one of the two calculations.

## Descriptive quantity reported BEFORE the test

D1. Correlation between the phi_v and phi_Z anomaly series. If it exceeds
    0.95 the test is near-degenerate and its result must be reported as
    uninformative regardless of outcome.

## Primary test

H1. Regressing ASL longitude anomaly on ZW3(v) phase anomaly yields a
    slope consistent with the ZW3(Z) value of +0.30 (replicated: +0.328
    full record, +0.308 and +0.207 in halves).
    Criterion: supported if the full-record slope is positive, p < 0.05,
    and its 95% interval overlaps [0.20, 0.45]; and if both split halves
    agree in sign.

No other test will be run on these data. Any further quantity computed is
exploratory and labelled as such.
